KT Photography project rules

- Preserve the warm editorial KT Photography visual system.
- Keep the website light; do not add dark public sections.
- Avoid generic templates, generic card layouts, glass effects, heavy shadows, and fake luxury decoration.
- Use local project assets; do not use remote placeholder images or generated imagery.
- Do not invent business facts, awards, reviews, numbers, venues, dates, or team claims.
- Keep desktop and tablet compositions optically centred.
- Use Saonara only for approved display typography.
- Use the existing sans-serif font for interface and body copy.
- Do not expose Experience in public navigation until it is explicitly re-enabled.
- Do not solve mobile responsiveness by stacking every section into identical full-width blocks.
- Preserve accessible semantics, keyboard navigation, focus states, and reduced-motion support.
- Run lint/type-check, production build, and rendered browser QA before claiming visual completion.
